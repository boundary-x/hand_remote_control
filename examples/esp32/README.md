# ESP32 수신 테스트

BLE 지원 ESP32와 MicroPython이 필요합니다. ESP32-S2는 지원하지 않습니다.

1. Thonny에서 이 폴더의 main.py와 ble_library.py를 ESP32에 저장합니다.
2. main.py를 실행합니다.
3. 웹앱에서 ESP32를 선택한 뒤 ESP32 장치에 연결합니다.
4. 웹앱 기능을 실행하면 Thonny 콘솔에 Received: 와 원래 데이터 문자열이 표시됩니다. 모터/LED 제어는 포함하지 않습니다.

데이터 형식은 기존 앱과 동일합니다. UTF-8 문자열과 줄바꿈을 사용합니다. 이 라이브러리의 수신 콜백은 문자열을 전달합니다. 분할 수신은 main.py에서 줄바꿈까지 합칩니다.

키패드 앱의 기본 ESP32 연결·수신은 사용자 실기기 검증을 완료했습니다. 이 앱의 실기기 동작은 별도로 확인해야 합니다.
